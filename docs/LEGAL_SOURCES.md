# LEGAL SOURCES

## 法規優先層級

1. **教育部現行命令／行政規則**
   - 《國民小學及國民中學學生獎懲準則》：2024-04-30 訂定，屬國中小學生獎懲的全國法規核心。
   - 《學校訂定教師輔導與管教學生辦法注意事項》：2024-02-05 修正，作為教師日常輔導與管教、一般管教措施與必要強制措施的核心依據。
2. **宜蘭縣政府地方規範／函文**
   - 《宜蘭縣國民中小學學生獎懲實施要點》（2005-11-15，府教學字第0940124753號函）目前仍見於縣內學校規範引用，但尚未取得縣府官方現行全文 URL，因此僅作地方來源索引，不據此做逐條結論。
   - 2024-07-03 府教學字第1130107212號函，縣內學校於2024年修訂獎懲規範時引用；公開全文尚未取得，因此不得推測函文內容。
3. **各校校規**
   - 僅在未來啟用學校專屬模式時載入，不得當作宜蘭縣通用規則。
4. **案例與外縣市手冊**
   - 僅供說明與風險提示，不得凌駕現行法規。

## 資料治理規則

- 只有 `status=verified` 的官方來源可支撐具體條文斷言。
- `needsOfficialSource` / `referencedBySchools` 只能顯示「有此地方來源／函文被引用」，不能推定其完整內容。
- 搜尋不到明確官方來源時，答案必須回到教育部全國規範，並標示地方規範仍待確認。
- 每筆來源保存 `lastVerified`，修法後必須重新驗證受影響 topic。
