# M2 Legal Decision Matrix

本表是產品維護用的「情境 → 教育部依據 → 回答邊界」對照，不取代正式法規全文。

| Topic | 主要依據 | 產品結論 | 邊界 |
| --- | --- | --- | --- |
| collective-punishment | 注意事項第14點第6款 | 🔴 不得因個人或少數人違規處罰其他或全體學生 | 若全班每個人都有實際違規，仍須依個別情節處理 |
| apology-reflection | 第23點第4款 | 🟢 可要求口頭道歉或書面自省 | 不得轉成羞辱、大量機械式抄寫或報復 |
| classroom-separation | 第23點第14款 | 🟡 教學場所一隅暫時保持距離，最多兩堂課 | 不得長期排除學習或設羞辱區 |
| temporary-other-class | 第23點第15款 | 🟡 經其他教師同意，行為當日得暫送其他班學習 | 不得變相長期轉班 |
| remove-from-scene | 第25點 | 🟡 一般管教無效或明顯不服管教且妨害現場活動，可請學務／輔導處派員帶離 | 不是教師任意把學生趕出教室 |
| after-school-retention | 第23點第11款 | 🟡 課後輔導／輔導課程的留置須法定代理人或實際照顧者同意 | 注意返家、安全與合理時間 |
| extracurricular-restriction | 第23點第10款＋第14點第7款 | 🟡 可限制正式課程以外學校活動 | 不得藉此剝奪正式課程或完整受教育權 |
| safety-search | 第29、30點 | 🔴 教師不得把搜身／翻書包當一般管教；符合安全條件時由學務處依程序進行 | 二人以上、陪同規則、全程錄影、紀錄與保密等程序不可省略 |
| low-achievement | 第20點 | 🔴 單純學業成就偏低不得處罰 | 若另有第21點所列違規行為，另依該行為處理 |

## 維護規則

1. 修法後先更新 source registry，再逐題驗證受影響 topic。
2. 不從搜尋摘要直接生成條文內容。
3. 宜蘭縣地方規範只有取得縣府官方全文後，才可覆蓋或補充全國通用答案。
4. 學校自訂規定只能在學校專屬模式使用。
5. 案例只能解釋風險，不能取代現行規定。
